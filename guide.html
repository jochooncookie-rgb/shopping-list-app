1. 도매상 현장에서 "한국에서 팔리는 물건인지" 확인하는 법

1-1. 현장 3분 루틴

① 바코드 13자리를 읽는다

  • 일본 상품의 JAN 코드는 45 또는 49로 시작하는 13자리입니다.
  • 이 13자리를 그대로 네이버 검색창 / 쿠팡 검색창에 입력하세요.
  • 결과가 나오면 → 이미 국내에서 팔리는 물건입니다. 판매자 수와 최저가를 바로 확인.
  • 결과가 없으면 → "블루오션"일 수도 있지만, "인증이 안 돼서 아무도 못 파는 물건"일 확률이 더 높습니다.

② 사진 한 장으로 이미지 검색

  • 네이버 앱 → 검색창 우측 렌즈 아이콘 → 촬영. 국내 네이버쇼핑 매칭이 가장 정확합니다.
  • Google Lens → 일본어 패키지 인식이 강함. 일본 원가·모델명 파악에 유리.
  • 쿠팡 앱 검색창의 카메라 아이콘 → 쿠팡 내 동일·유사 상품 검색.

③ 브랜드명을 한글 음차로 바꿔 재검색

  • 카타카나/한자 브랜드는 이미지 검색이 놓치는 경우가 많습니다.
  • 예: 資生堂 → 시세이도, ロート → 로토, 花王 → 카오

④ 일본 소매가를 같이 확인한다

  • 같은 JAN 코드를 아마존 재팬 / 라쿠텐에 넣어 일본 소매가를 확인.
  • 도매가가 일본 소매가 대비 충분히 싸지 않으면, 한국 소비자가 직구로 사는 게 더 쌉니다. 이 경우 사업이 성립하지 않습니다.

⑤ 정식 총판이 있는지 본다

  • 제조사 공식 사이트에서 韓国 正規代理店 / 韓国 総代理店 검색.
  • 총판이 있으면 → 병행수입이 됩니다. 세관 통관보류·상표권 분쟁 리스크가 붙습니다.

1-3. 현장에서 반드시 찍어둘 사진

나중에 관세사·인증기관에 물어볼 때 이게 없으면 답을 못 받습니다.

  • 상품 정면 (브랜드·제품명)
  • 바코드(JAN 13자리)
  • 뒷면 라벨 전체 — 성분표, 제조사, 원산지(原産国)
  • 전기제품이면 전원 표시부 (100V / W 숫자)
  • 대상 연령 표기 (対象年齢 ○歳以上) — 만 13세 이하면 어린이제품 규제 대상
  • 사입 단가 (税抜 세금 제외인지 税込 포함인지 확인)

1-4. 반드시 받아야 할 서류

도매상에서 현금으로 사고 영수증을 안 받으면, 통관도 안 되고 쿠팡·네이버 브랜드 등록도 막힙니다.
  • 인보이스 (請求書 또는 領収書) — 상품명·수량·단가·총액·판매처명 명시
  • 가능하면 면세 처리 (免税). 일본 소비세 10%를 아낄 수 있습니다.

3. 정식수입 시 세금과 관세사 수수료

3-1. 대전제 — 판매 목적이면 면세 없음

  • 150달러 소액면세는 "자가사용" 전용입니다. 판매 목적 수입은 금액과 무관하게 적용받지 못합니다.
  • 목록통관(간이통관)도 불가. 판매용은 정식 수입신고를 해야 합니다.
  • 즉, 10만원어치를 들여와도 관세·부가세와 통관 절차가 그대로 붙습니다.

3-2. 계산 공식

과세가격(CIF) = 물품가 + 일본 국내운송·포장비 + 국제운임 + 보험료
관세          = 과세가격 × 관세율
부가세        = (과세가격 + 관세) × 10%
핵심: 부가세 10%는 사업자등록이 있으면 매입세액으로 공제·환급됩니다.
→ 실질적으로 부담하는 세금은 "관세"뿐입니다. 부가세는 잠시 나갔다가 돌아오는 돈입니다.

3-4. 한-일 FTA는 없다 (RCEP 주의)

  • 한국과 일본 사이에는 양자 FTA가 없습니다.
  • RCEP(2022.2.1 발효)이 한-일 간 최초의 협정 관계이지만, 소비재는 양허 제외이거나 장기 철폐 대상이 많아 인하 폭이 작고, RCEP 원산지증명서를 수출자에게서 받아야만 적용됩니다.
  • 도매상에서 현금 구매하는 방식으로는 원산지증명서를 받을 수 없습니다. → 실무상 WTO 협정세율/기본세율이 적용된다고 보고 계산하세요.

3-6. 그 밖에 붙는 실비

  • 국제운송비 (EMS / 특송 / 항공 / 해운 LCL)
  • 창고보관료, D/O 차지, 하역비 — 합쳐서 3~10만원 수준
  • 국내 내륙운송비
  • 특송사(EMS·DHL)를 쓰면 통관 대행이 포함되거나 저렴한 경우가 있습니다. 소량이면 특송이 유리

4-2. 로켓배송(직매입)에 대한 현실적 조언

"로켓배송 수수료가 얼마냐"는 질문 자체가 성립하지 않습니다. 로켓배송은 쿠팡이 셀러에게서 물건을 사가는 구조라, 수수료율이 아니라 납품 공급가를 협상합니다.

  • 업계 체감상 쿠팡이 가져가는 몫은 판매가의 30~45% 수준입니다.
  • 다이내믹 프라이싱으로 쿠팡이 최저가 판매를 하고, 그 차액 부담을 차기 발주 시 공급가 인하 요구로 넘기는 사례가 보고됩니다.
  • 입점 조건: 안정적·지속적 재고 공급 능력, 세금계산서 발행, 인증서류 완비.
일본 도매상에서 그때그때 소량 사입하는 방식은 "지속적 재고 공급"이 불가능하므로 로켓배송에 사실상 부적합합니다. 발주가 들어왔는데 물건이 없으면 페널티를 받고 발주가 정지됩니다.

소규모 일본 사입의 현실적인 답: 마켓플레이스로 시작 → 회전이 검증된 SKU만 로켓그로스로 이관.

정확한 구간별 금액은 쿠팡 Wing 판매자센터의 요금 시뮬레이터에서 본인 상품의 실제 부피·무게로 확인하는 것이 유일하게 정확한 방법입니다.

4-5. 마진 계산 시 반드시 빼야 할 것

판매가
 − 판매수수료(4~10.9%) − 그 부가세
 − 로켓그로스 물류비 (해당 시)
 − 월 서비스 이용료 55,000원 (매출 나누기)
 − 광고비  ← 신규 셀러는 이게 제일 큼
 − 쿠폰·이벤트 분담금
 − 반품·교환 손실
 − 상품 실질원가
= 순마진
광고비를 빼먹는 것이 초보 셀러의 1번 실수입니다. 쿠팡에서 신규 리스팅은 광고 없이 노출되지 않습니다. 초기에는 매출의 10~20%를 광고비로 잡으세요.

5. 사진만 찍어서 확인하는 방법

5-1. 지금 당장 쓸 수 있는 것

도구쓰는 법강점
네이버 앱
스마트렌즈		검색창 우측 렌즈 아이콘 → 촬영국내 네이버쇼핑 매칭 최강. 국내 판매 여부·최저가 즉시 확인
Google Lens구글 앱 / 크롬 → 카메라일본어 패키지·모델명 인식 최강. 일본 원가 파악에 유리
쿠팡 앱
이미지 검색		검색창 카메라 아이콘쿠팡 내 경쟁 상품·판매자 수 확인
바코드 스캔렌즈의 바코드 모드, 또는 13자리 직접 입력가장 정확. 이미지 검색이 실패해도 JAN 코드는 정확히 매칭

5-2. 실전 워크플로 (도매상에서 1분)

1. 바코드 촬영 → JAN 13자리 확보
2. 네이버 검색창에 13자리       → 국내 판매 여부 + 최저가
3. 쿠팡 검색창에 13자리         → 쿠팡 경쟁 강도 + 판매자 수
4. 아마존 재팬에 13자리         → 일본 소매가
5. 뒷면 라벨 촬영               → 인증 대상 여부 판단용
판단 기준
• 한국 최저가 < 일본 소매가 × 1.5 → 마진 안 남. 넘어가세요.
• 한국 최저가 > 사입가 × 2.5 → 검토 가치 있음
  (부대비용 38% + 쿠팡 15% + 광고 15%를 감당해야 함)

5-3. AI에게 사진을 던지는 방법

Claude 앱 / ChatGPT 앱에 매장 사진을 올리고 이렇게 물으면 됩니다.

이 일본 상품 사진에서 브랜드명, 제품명, 용량,
JAN 바코드 번호를 읽어줘.
한국에서 검색할 때 쓸 한글 검색어 후보 3개를 만들어줘.
이 카테고리가 한국에서 KC인증이나 식약처 등록
대상인지도 알려줘.
  • 일본어를 못 읽어도 되고, 카타카나 브랜드를 한글로 음차하는 것까지 한 번에 해결됩니다.
  • 여러 개를 한 번에 찍어서 한꺼번에 올려도 됩니다.
이 저장소의 사입 판정기가 위 과정을 한 화면에 묶어둔 것입니다. 사진 → 렌즈 넘기기, 바코드 → 4개 사이트 검색, 마진 계산까지 한 번에.

6. 첫 출장 전 체크리스트

출발 전 (한국에서)

  • 사업자등록증 발급 (부가세 환급을 받으려면 필수)
  • 통관고유부호 발급 (관세청, 무료)
  • 관세사 1곳 미리 컨택 — "일본에서 소량 사입할 건데 예상 비용 알려달라"
  • 취급할 카테고리의 인증 요건 확인 (2번 섹션)
  • 쿠팡 Wing / 네이버 스마트스토어 입점 신청

현장에서 (도매상)

  • 상품 정면 + 바코드 + 뒷면 라벨 촬영
  • JAN 13자리 → 네이버·쿠팡·아마존재팬 3중 검색
  • 사입가 税抜/税込 확인
  • 인보이스(請求書) 수령 — 없으면 사지 말 것
  • 가능하면 면세(免税) 처리

귀국 후

  • 인보이스 + 사진을 관세사에게 전달 → HS코드·세율 확정
  • 인증 대상이면 판매 전에 인증 완료 (통관됐다고 판매 가능한 것 아님)
  • 실질 원가 계산 → 쿠팡 수수료·광고비 반영 → 판매가 결정
