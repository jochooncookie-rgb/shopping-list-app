| 파일 | 설명 |
|---|---|
| [`index.html`](index.html) | 랜딩 페이지 (Pages 루트 진입점) |

## 일본 사입 판정기 사용법

도매상에서 폰으로 쓰는 툴입니다.

1. **사진 → 형태 검색** — 상품을 찍어 네이버·구글 렌즈로 넘깁니다. 바코드가 없는 노브랜드 잡화용
2. **바코드 스캔** — 일본 JAN(45/49로 시작하는 13자리)을 카메라로 읽고 체크섬을 검증합니다
3. **국내 판매 확인** — 네이버쇼핑·쿠팡·아마존재팬·라쿠텐을 한 번에 검색
4. **인증 리스크** — 카테고리를 고르면 KC/식약처 요건과 위험도를 표시
5. **마진 계산** — 사입가·관세·통관수수료·쿠팡 수수료·광고비까지 반영한 개당 순마진과 손익분기 판매가
6. **후보 저장** — 사진 썸네일과 함께 localStorage에 쌓고 CSV로 내보내기

### 이미지 검색은 왜 직접 안 하나

상품 이미지 유사도 검색을 하려면 상품 이미지 인덱스가 있어야 하는데, 그건 네이버·구글이 가진 자산이라
복제할 수 없습니다. 그래서 **자체 검색 대신 인덱스를 가진 앱으로 넘기는 방식**을 씁니다.
`navigator.share({files})`(Web Share API)로 네이티브 공유 시트를 띄우면 네이버·구글 앱이 대상으로 뜹니다.
지원하지 않는 브라우저에서는 앨범에서 직접 렌즈에 넣는 방법을 안내합니다.

### 카메라·공유 주의

- **바코드 스캔**은 `BarcodeDetector` API를 씁니다. **안드로이드 크롬 + HTTPS(또는 localhost)** 에서만
  동작합니다. `file://` 로 열거나 iOS Safari에서는 카메라가 뜨지 않으니 숫자를 직접 입력하세요.
- **사진 촬영·첨부는 모든 브라우저에서 동작**합니다(`<input type="file" capture>`). 렌즈로 바로 넘기는
  공유 시트만 Web Share API 지원 여부를 탑니다.
- 사진은 최대변 320px JPEG로 줄여 저장하므로 한 건당 5KB 내외입니다.

로컬에서 카메라까지 테스트하려면:

```sh
python3 -m http.server 8000
# → http://localhost:8000/sourcing.html
```

### 계산 기준

모든 금액은 **부가세를 제외한 공급가액 기준**입니다. 수입 부가세와 매출 부가세는 사업자라면 상계되므로
마진에 영향을 주지 않습니다.

관세율·수수료는 참고치입니다. 실제 세율은 HS코드 10자리로 결정되므로 금액이 큰 건은 관세사 확인이 필요합니다.

## 법령 근거 직접 확인하기

가이드에 나오는 관세·부가세 서술은 2차 출처(관세청 안내를 인용한 실무 자료)를 교차 확인한
것입니다. 법령 원문으로 직접 검증하려면 국가법령정보 공동활용 API를 쓰세요.

```sh
# 1) https://open.law.go.kr 에서 오픈API 활용 신청 (무료, 즉시~1일)
# 2) 승인된 ID(보통 이메일 앞부분)를 OC 값으로 사용
./tools/verify-law.sh <OC>
```

확인 대상 조문:

| 법령 | 조문 | 가이드에서 쓰인 곳 |
|---|---|---|
| 관세법 | 제81조 | 간이세율의 적용 |
| 관세법 | 제96조 | 여행자 휴대품·이사물품 감면 (800달러 면세) |
| 관세법 시행령 | 제96조 | 간이세율 배제 대상 (상업용 수량) |
| 관세법 시행규칙 | 제48조 | 관세가 면제되는 여행자 휴대품 (자가사용 요건) |
| 부가가치세법 | 제35조 | 수입세금계산서 |
| 부가가치세법 | 제38조 | 매입세액의 공제 |

> Claude Code 세션에서는 실행되지 않습니다. 이 환경의 이그레스 정책이 `law.go.kr`,
> `data.go.kr`, `customs.go.kr` 를 포함한 정부 도메인에 대해 CONNECT 403을 반환합니다.
> 로컬 PC에서 실행하세요.
