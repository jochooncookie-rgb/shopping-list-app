| [`docs/일본사입-국내판매-실무가이드.md`](docs/일본사입-국내판매-실무가이드.md) | 인증 요건, 관세 계산, 쿠팡 채널별 수수료 상세 가이드 |

## 일본 사입 판정기 사용법

도매상에서 폰으로 쓰는 툴입니다.

1. **바코드 스캔** — 일본 JAN(45/49로 시작하는 13자리)을 카메라로 읽고 체크섬을 검증합니다
2. **국내 판매 확인** — 네이버쇼핑·쿠팡·아마존재팬·라쿠텐을 한 번에 검색
3. **인증 리스크** — 카테고리를 고르면 KC/식약처 요건과 위험도를 표시
4. **마진 계산** — 사입가·관세·통관수수료·쿠팡 수수료·광고비까지 반영한 개당 순마진과 손익분기 판매가
5. **후보 저장** — localStorage에 쌓고 CSV로 내보내기

### 카메라 스캔 주의

`BarcodeDetector` API를 씁니다. **안드로이드 크롬 + HTTPS(또는 localhost)** 에서만 동작합니다.
`file://` 로 열거나 iOS Safari에서는 카메라가 뜨지 않으니 바코드 숫자를 직접 입력하세요.

로컬에서 카메라까지 테스트하려면:

```sh
python3 -m http.server 8000
# → http://localhost:8000/sourcing.html
```

### 계산 기준

모든 금액은 **부가세를 제외한 공급가액 기준**입니다. 수입 부가세와 매출 부가세는 사업자라면 상계되므로
마진에 영향을 주지 않습니다.

관세율·수수료는 참고치입니다. 실제 세율은 HS코드 10자리로 결정되므로 금액이 큰 건은 관세사 확인이 필요합니다.
