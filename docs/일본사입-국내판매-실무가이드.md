# 일본 소규모 사입 → 쿠팡/네이버 판매 실무 가이드

> 기준 시점: 2026년 8월 · 공개 자료 기반 정리
> 세율·수수료는 품목과 시점에 따라 달라집니다. 금액이 큰 건은 반드시 관세사 확인 후 진행하세요.

---

## 0. 먼저 알아야 할 것 — 무엇이 진짜 리스크인가

소규모 일본 사입에서 사업을 죽이는 순서는 이렇습니다.

| 순위 | 리스크 | 왜 |
|---|---|---|
| 1 | **인증·규제 (KC / 식약처)** | 물건이 통관 자체가 안 되거나, 통관돼도 판매가 불법. 인증비가 사입액보다 큰 경우가 흔함 |
| 2 | **상표권 / 병행수입** | 세관 통관보류, 플랫폼 판매중지, 상표권자 경고장 |
| 3 | **관세·부가세** | 실제로는 제일 작음. 대체로 사입가의 8~13% 수준 |

> 초보자가 관세만 계산하다가 1번에서 전멸합니다. **"이 물건 관세 얼마?"보다 "이 물건 인증 대상이야?"를 먼저 물어야 합니다.**

## 1. 도매상 현장에서 "한국에서 팔리는 물건인지" 확인하는 법

### 1-1. 현장 3분 루틴

물건을 집었을 때 이 순서로 돌리세요.

**① 바코드 13자리를 읽는다**
- 일본 상품의 JAN 코드는 **`45`** 또는 **`49`** 로 시작하는 13자리입니다.
- 이 13자리를 그대로 **네이버 검색창 / 쿠팡 검색창**에 입력하세요.
- 결과가 나오면 → 이미 국내에서 팔리는 물건입니다. 판매자 수와 최저가를 바로 확인.
- 결과가 없으면 → "블루오션"일 수도 있지만, **"인증이 안 돼서 아무도 못 파는 물건"일 확률이 더 높습니다.** 2번 섹션을 반드시 확인하세요.

**② 사진 한 장으로 이미지 검색**
- **네이버 앱** → 검색창 우측 **렌즈 아이콘** → 촬영. 국내 네이버쇼핑 매칭이 가장 정확합니다.
- **Google Lens** (구글 앱 / 크롬) → 일본어 패키지 인식이 강함. 일본 원가·모델명 파악에 유리.
- **쿠팡 앱** 검색창의 카메라 아이콘 → 쿠팡 내 동일·유사 상품 검색.

**③ 브랜드명을 한글 음차로 바꿔 재검색**
- 카타카나/한자 브랜드는 이미지 검색이 놓치는 경우가 많습니다.
- 예: 資生堂 → 시세이도, ロート → 로토, 花王 → 카오, DHC → 디에이치씨
- 네이버쇼핑에서 한글 브랜드명 + 제품 라인명으로 검색.

**④ 일본 소매가를 같이 확인한다**
- 같은 JAN 코드를 **아마존 재팬 / 라쿠텐**에 넣어 일본 소매가를 확인.
- 도매가가 일본 소매가 대비 충분히 싸지 않으면, 한국 소비자가 직구로 사는 게 더 싸집니다. 이 경우 사업이 성립하지 않습니다.

**⑤ 정식 총판이 있는지 본다**
- 제조사 공식 사이트에서 `韓国 正規代理店` / `韓国 総代理店` 검색.
- 총판이 있으면 → 병행수입이 됩니다. 세관 통관보류·상표권 분쟁 리스크가 붙습니다.

### 1-2. 검색 결과 해석표

| 검색 결과 | 의미 | 판단 |
|---|---|---|
| 판매자 다수, 가격 경쟁 심함 | 이미 레드오션 | 사입가 우위 없으면 포기 |
| 판매자 1~3곳, 가격 높음 | 총판 또는 소수 병행수입 | 기회 있음. 단 상표권 확인 필수 |
| "해외직구" 표기만 존재 | 국내 정식 수입 없음 | 인증 장벽이 있을 가능성 높음 |
| 검색 결과 전무 | 미개척 또는 판매 불가 | **인증 확인 전에는 절대 사입 금지** |

### 1-3. 현장에서 반드시 찍어둘 사진

나중에 관세사·인증기관에 물어볼 때 이게 없으면 답을 못 받습니다.

- [ ] 상품 정면 (브랜드·제품명)
- [ ] **바코드(JAN 13자리)**
- [ ] **뒷면 라벨 전체** — 성분표, 제조사, 원산지(`原産国`), 제조국
- [ ] 전기제품이면 **전원 표시부** (`100V` / `W` 숫자)
- [ ] **대상 연령 표기** (`対象年齢 ○歳以上`) — 만 13세 이하면 어린이제품 규제 대상
- [ ] 사입 단가 (`税抜` 세금 제외인지 `税込` 포함인지 확인)

### 1-4. 반드시 받아야 할 서류

도매상에서 현금으로 사고 영수증을 안 받으면, 통관도 안 되고 쿠팡·네이버 브랜드 등록도 막힙니다.

- **인보이스 (`請求書` 또는 `領収書`)** — 상품명·수량·단가·총액·판매처명이 명시된 것
- 가능하면 **면세 처리** (`免税` / Tax Free, 사업자 수출용). 일본 소비세 10%를 아낄 수 있습니다.

## 2. 인증 — 실제 관문

**품목별로 이것부터 확인하세요.**

| 품목 | 필요한 것 | 대략 비용 / 기간 | 소규모 적합도 |
|---|---|---|---|
| 의류·가방·문구·잡화 (전기 X, 아동용 X) | 별도 인증 대체로 없음. 섬유는 품질표시 의무 | 거의 없음 | ⭕ **가장 적합** |
| 화장품 (스킨케어·색조·샴푸 등) | 화장품책임판매업 등록(식약처) + **책임판매관리자 선임** + 표준통관예정보고(대한화장품협회) | 등록비는 수만원대이나, 책임판매관리자 자격 요건이 실질 장벽 (외부 위탁 가능, 월 비용 발생) | 🔺 준비 필요 |
| 식품·과자·건강기능식품·주류 | 수입식품등 수입판매업 영업등록 + 위생교육 + **해외제조업소 등록** + **최초 정밀검사** | 정밀검사 **품목당 50~100만원**, 약 14일 | 🔺 품목 수 적을 때만 |
| 전기제품 (콘센트 꽂는 것) | KC 안전인증 또는 안전확인 (+ 일본 100V ↔ 한국 220V 문제) | 안전확인 수십~수백만원, 안전인증은 공장심사 포함 | ❌ 소규모 비추천 |
| 무선기기 (블루투스·와이파이) | 전파법 적합성평가 (적합등록/적합인증) | 수십~수백만원 | ❌ 소규모 비추천 |
| 만 13세 이하 어린이 제품 | 어린이제품 안전특별법 KC 인증 | 수십~수백만원 | ❌ 소규모 비추천 |
| 의료기기·의약외품 (파스, 안약, 습포제 등) | 식약처 허가/신고 | 매우 높음 | ❌ 사실상 불가 |
| 위생용품 (일회용 식기 등) | 위생용품 수입신고 | 중간 | 🔺 |

> **일본 드럭스토어의 인기 품목(동전파스, 안약, 감기약, 건강보조제)은 대부분 의약품/의약외품/건강기능식품**이라 소규모로는 손댈 수 없습니다. 유튜브 후기만 보고 들어가면 100% 막힙니다.

**결론: 첫 사입은 의류·잡화·문구·주방소품(전기 없는 것)·팬시류로 시작하는 것이 정석입니다.**

## 3. 정식수입 시 세금과 관세사 수수료

### 3-1. 대전제 — 판매 목적이면 면세 없음

- **150달러 소액면세는 "자가사용" 전용입니다.** 판매 목적 수입은 금액과 무관하게 적용받지 못합니다.
- **목록통관(간이통관)도 불가.** 판매용은 정식 수입신고를 해야 합니다.
- 즉, 10만원어치를 들여와도 관세·부가세와 통관 절차가 그대로 붙습니다.

### 3-2. 계산 공식

```
과세가격(CIF) = 물품가 + 일본 국내운송·포장비 + 국제운임 + 보험료
관세          = 과세가격 × 관세율
부가세        = (과세가격 + 관세) × 10%
```

**핵심: 부가세 10%는 사업자등록이 있으면 매입세액으로 공제·환급됩니다.**
→ **실질적으로 부담하는 세금은 "관세"뿐입니다.** 부가세는 현금흐름상 잠시 나갔다가 돌아오는 돈입니다.

### 3-3. 대표 관세율 (기본세율 기준 · 참고용)

| 품목 | 대략 관세율 |
|---|---|
| 화장품 | 6.5% |
| 의류 (직물제) | 13% |
| 신발 | 13% |
| 가방·피혁제품 | 8% |
| 완구 | 8% |
| 문구·주방용품·일반잡화 | 8% |
| 일반 전자제품 | 8% (컴퓨터·반도체 등 ITA 품목은 0%) |
| 가공식품 | 8~30%+ (편차 매우 큼) |

> ⚠️ 실제 세율은 **HS코드 10자리**로 결정됩니다. 위 표는 감을 잡기 위한 참고치일 뿐입니다.
> 정확한 확인: [관세법령정보포털(UNIPASS)](https://unipass.customs.go.kr) 또는 관세청 콜센터 **125**

### 3-4. 한-일 FTA는 없다 (RCEP 주의)

- 한국과 일본 사이에는 **양자 FTA가 없습니다.**
- **RCEP**(2022.2.1 발효)이 한-일 간 최초의 협정 관계이지만,
  - 소비재는 양허 제외이거나 장기 철폐 대상이 많아 인하 폭이 작고,
  - **RCEP 원산지증명서를 수출자에게서 받아야만** 적용됩니다.
- 도매상에서 현금 구매하는 방식으로는 원산지증명서를 받을 수 없습니다.
  → **실무상 WTO 협정세율/기본세율이 적용된다고 보고 계산하세요.**

### 3-5. 관세사 통관수수료

| 항목 | 금액 |
|---|---|
| 통관수수료(수입신고 대행) | **과세가격의 약 0.2%, 최저 30,000원** (VAT 별도) |
| 소액 건 실무 체감 | 건당 **3~5만원** |
| 과세 방식 | B/L 1건 = 수입신고 1건 → **건당 부과** |

> 여러 도매상에서 산 물건이라도 **한 번에 묶어 한 건으로 보내면 통관수수료는 1회분**입니다. 소량을 나눠 보내면 최저 3만원이 매번 붙어 배보다 배꼽이 커집니다.

### 3-6. 그 밖에 붙는 실비

- 국제운송비 (EMS / 특송 / 항공 / 해운 LCL)
- 창고보관료, D/O 차지, 하역비 — 일반 화물의 경우 합쳐서 **3~10만원 수준**
- 국내 내륙운송비
- (특송사 EMS·DHL 등을 쓰면 통관 대행이 포함되거나 훨씬 저렴한 경우가 있습니다. 소량이면 특송이 유리)

### 3-7. 실제 계산 예시

**조건: 일본 도매상에서 100만원어치 사입, 관세율 8% 품목**

| 항목 | 금액 |
|---|---|
| 물품가 | 1,000,000원 |
| 일본 국내배송·포장 | 50,000원 |
| 국제운송비 | 150,000원 |
| **과세가격(CIF)** | **1,200,000원** |
| 관세 (8%) | 96,000원 |
| 부가세 ((120만+9.6만)×10%) | 129,600원 *(→ 환급 가능)* |
| 관세사 통관수수료 (최저 3만 + VAT) | 33,000원 |
| 창고료·D/O·국내운송 등 | 약 50,000원 |

- **현금 지출 총액**: 1,458,600원
- **실질 원가** (부가세 환급 반영): **1,379,000원**
- **사입가 대비 부대비용 = 약 37.9%** ← 그중 세금은 9.6만원(9.6%)뿐이고, **나머지는 운송·통관 실비**

> 👉 **소량 사입의 진짜 적은 관세가 아니라 물류·통관 고정비입니다.** 100만원 사입에 통관 고정비 8만원이면 8%지만, 500만원 사입이면 1.6%로 떨어집니다. **로트를 키우는 것이 마진을 만드는 유일한 길입니다.**

## 4. 쿠팡 수수료 — 세 가지 모델을 구분하세요

### 4-1. 모델 비교

| 구분 | 로켓배송 (직매입) | 로켓그로스 | 마켓플레이스 (판매자배송) |
|---|---|---|---|
| 누가 파나 | **쿠팡이 매입해서 판매** | 셀러가 판매, 쿠팡이 물류 | 셀러가 판매·배송 전부 |
| 가격 결정 | **쿠팡** | 셀러 | 셀러 |
| 비용 구조 | 수수료 아님 → **공급가 협상** | 판매수수료 + 물류비 | 판매수수료만 |
| 체감 부담률 | 판매가의 **약 30~45%** | 약 **20~30%** | 약 **13~18%** |
| 재고 리스크 | 쿠팡이 부담 | 셀러 | 셀러 |

### 4-2. 로켓배송(직매입)에 대한 현실적 조언

**"로켓배송 수수료가 얼마냐"는 질문 자체가 성립하지 않습니다.** 로켓배송은 쿠팡이 셀러에게서 물건을 **사가는** 구조라, 수수료율이 아니라 **납품 공급가**를 협상합니다.

- 업계 체감상 쿠팡이 가져가는 몫은 **판매가의 30~45%** 수준입니다.
- 게다가 다이내믹 프라이싱으로 쿠팡이 최저가 판매를 하고, 그 차액 부담을 **차기 발주 시 공급가 인하 요구**로 넘기는 사례가 보고됩니다.
- **입점 조건: 안정적·지속적 재고 공급 능력, 세금계산서 발행, 인증서류 완비.**

> 🚫 **일본 도매상에서 그때그때 소량 사입하는 방식은 "지속적 재고 공급"이 불가능하므로 로켓배송에 사실상 부적합합니다.**
> 발주가 들어왔는데 물건이 없으면 페널티를 받고 발주가 정지됩니다.
> **소규모 일본 사입의 현실적인 답은 마켓플레이스로 시작 → 회전이 검증된 SKU만 로켓그로스로 이관입니다.**

### 4-3. 마켓플레이스 (판매자배송)

| 항목 | 금액 |
|---|---|
| 카테고리별 판매수수료 | **4% ~ 10.9%** (부가세 별도 표기, 정산 시 VAT 포함 청구) |
| 월 서비스 이용료 | **55,000원** — 월매출 100만원 초과 시 (가전·디지털은 500만원 초과 시) |
| 배송비 관련 수수료 | 배송비 금액의 약 3.3% |

**카테고리별 대략적인 수수료 수준**

| 카테고리 | 수수료 |
|---|---|
| 식품·생필품 | 4~6% |
| 생활용품·건강용품 | 7~9% |
| 가전·디지털 | 약 7.8% |
| 패션의류 | 약 10.5% |
| 화장품 | 10~11% |

### 4-4. 로켓그로스

**판매수수료 (4~10.9%) + 물류비**로 구성됩니다.

| 항목 | 내용 |
|---|---|
| 판매수수료 | 카테고리별 4~10.9% |
| 입출고·배송요금 | **사이즈·무게 기준 6단계** 구간별 (2025.1.6 개편) |
| 보관료 | 보관 기간·부피 기준 |
| 반품비 | 월 20건까지 무상, 초과분 유료 |
| 반출비 | 건당 300원 |
| 폐기비·부가서비스료 | 별도 |

> 2025년 개편으로 물류비가 평균 20~30% 인상되었고, 대형 상품은 50% 이상 오른 경우도 있습니다.
> **입출고비·배송비 프로모션은 2027.1.31.까지 유효** — 그 이후 원가 구조가 바뀔 수 있으니 장기 사업계획에 반영하세요.
> **정확한 구간별 금액은 쿠팡 Wing 판매자센터의 요금 시뮬레이터에서 본인 상품의 실제 부피·무게로 확인하는 것이 유일하게 정확한 방법입니다.**

### 4-5. 마진 계산 시 반드시 빼야 할 것

```
판매가
 − 판매수수료(4~10.9%) − 그 부가세
 − 로켓그로스 물류비 (해당 시)
 − 월 서비스 이용료 55,000원 (매출 나누기)
 − 광고비  ← 신규 셀러는 이게 제일 큼
 − 쿠폰·이벤트 분담금
 − 반품·교환 손실 (일본 상품은 반품 재판매 어려움)
 − 상품 실질원가 (섹션 3-7의 "실질 원가")
= 순마진
```

> 💡 **광고비를 빼먹는 것이 초보 셀러의 1번 실수입니다.** 쿠팡에서 신규 리스팅은 광고 없이 노출되지 않습니다. 초기에는 매출의 10~20%를 광고비로 잡으세요.

## 5. 사진만 찍어서 확인하는 방법

### 5-1. 지금 당장 쓸 수 있는 것 (앱 설치만)

| 도구 | 쓰는 법 | 강점 |
|---|---|---|
| **네이버 앱 스마트렌즈** | 검색창 우측 렌즈 아이콘 → 촬영 | **국내 네이버쇼핑 매칭 최강.** 국내 판매 여부·최저가 즉시 확인 |
| **Google Lens** | 구글 앱 / 크롬 → 카메라 | **일본어 패키지·모델명 인식 최강.** 일본 원가 파악에 유리 |
| **쿠팡 앱 이미지 검색** | 검색창 카메라 아이콘 | 쿠팡 내 경쟁 상품·판매자 수 확인 |
| **바코드 스캔** | 네이버 렌즈의 바코드 모드, 또는 13자리 직접 입력 | **가장 정확.** 이미지 검색이 실패해도 JAN 코드는 정확히 매칭됨 |

### 5-2. 실전 워크플로 (도매상에서 1분)

```
1. 바코드 촬영 → JAN 13자리 확보
2. 네이버 검색창에 13자리 붙여넣기       → 국내 판매 여부 + 최저가
3. 쿠팡 검색창에 13자리 붙여넣기         → 쿠팡 경쟁 강도 + 판매자 수
4. 아마존 재팬에 13자리 붙여넣기         → 일본 소매가 (직구 대비 경쟁력 확인)
5. 뒷면 라벨 촬영                        → 인증 대상 여부 판단용 (섹션 2)
```

**판단 기준**
- 한국 최저가 < 일본 소매가 × 1.5 → **마진 안 나옴. 넘어가세요.**
- 한국 최저가 > 사입가 × 2.5 → 검토 가치 있음 (부대비용 38% + 쿠팡 15% + 광고 15%를 감당해야 함)

### 5-3. AI에게 사진을 던지는 방법 (반자동)

Claude 앱 / ChatGPT 앱에 매장 사진을 올리고 이렇게 물으면 됩니다.

```
이 일본 상품 사진에서 브랜드명, 제품명, 용량, JAN 바코드 번호를 읽어줘.
그리고 한국에서 검색할 때 쓸 한글 검색어 후보 3개를 만들어줘.
이 카테고리가 한국에서 KC인증이나 식약처 등록 대상인지도 알려줘.
```

- 일본어를 못 읽어도 되고,
- 카타카나 브랜드를 한글로 음차하는 것까지 한 번에 해결됩니다.
- **여러 개를 한 번에 찍어서 한꺼번에 올려도 됩니다.**

### 5-4. 완전 자동화 (직접 만들 경우)

가능합니다. 구성은 이렇습니다.

```
사진 업로드
  ↓ 멀티모달 AI (이미지 → 브랜드/제품명/JAN 추출)
  ↓ 네이버 검색 오픈API (쇼핑 검색: 최저가, 판매자 수, 상품 수)
  ↓ 일본 소매가 조회
  ↓ 마진 계산기 (사입가 + 관세 + 물류 + 쿠팡 수수료 → 예상 순마진)
= "사입 O / X" 판정 카드
```

- **네이버 개발자센터 오픈API는 무료**입니다 (검색 API, 일 25,000회).
- 결과를 표로 쌓아두면 "이번 출장 사입 후보 리스트"가 그대로 만들어집니다.

## 6. 첫 출장 전 체크리스트

**출발 전 (한국에서)**
- [ ] 사업자등록증 발급 (부가세 환급을 받으려면 필수)
- [ ] **통관고유부호** 발급 (관세청, 무료)
- [ ] 관세사 1곳 미리 컨택 — "일본에서 소량 사입할 건데 예상 비용 알려달라"
- [ ] 취급할 카테고리의 인증 요건 확인 (섹션 2)
- [ ] 쿠팡 Wing / 네이버 스마트스토어 입점 신청

**현장에서 (도매상)**
- [ ] 상품 정면 + 바코드 + 뒷면 라벨 촬영
- [ ] JAN 13자리 → 네이버·쿠팡·아마존재팬 3중 검색
- [ ] 사입가 `税抜`/`税込` 확인
- [ ] **인보이스(請求書) 수령** — 없으면 사지 말 것
- [ ] 가능하면 면세(免税) 처리

**귀국 후**
- [ ] 인보이스 + 사진을 관세사에게 전달 → HS코드·세율 확정
- [ ] 인증 대상이면 판매 전에 인증 완료 (통관됐다고 판매 가능한 것 아님)
- [ ] 실질 원가 계산 → 쿠팡 수수료·광고비 반영 → 판매가 결정
